# Rift Runner
A one-stage, top-down spaceship shooter. Open `index.html` in a modern browser.

- **Touch:** hold one of the eight direction buttons to steer. Turn Auto Aim off to reveal a separate aim/fire stick. The controls stay below the arena.
- **Steering:** the ship keeps its momentum when you release the controls. Steer against the drift to brake or reverse.
- **Desktop:** WASD flies; arrows aim and fire, or use the mouse and hold to shoot. Escape/P pauses.
- **Sound and shake:** use the switches at the top. Audio starts when you launch a run. Use Test sound to try the cannon sound before launch. Reduced-motion settings default shake off.

Enemy waves share one arena. Each run starts fresh; only local settings and your best score carry over. No upgrades, external dependencies, or network services.
