# Red Grin simulator
Hangar → Cockpit → Add Flight Mode → Simulator: Red Grin → Start Simulator.
This is an isolated client-only exercise, not a solo/online career sortie. The simulator temporarily equips a stock fighter and restores the cockpit fit at exit. Only the moving pirate frigate is spawned. Fighter defeat and victory can be rematched without repairs. No credits, career, hull certificate, parking, carrier resources, or Galaxy Map state should change.

The six-gun frigate has one active three-gun bank at a time. Each bank traverses 30 degrees forward and aft of straight out. Each burst fires three pulses, nine shots total, before a shared reload. The normal arena soundtrack respects the Sound setting. The broadside uses heavy cannon audio and proximity-based shake; Reduce Motion and the game’s screen shake setting are respected.
