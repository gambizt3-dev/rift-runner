# Multicrew ships

- Corvettes, frigates, cruisers and carriers are multicrew classes. Fighter and vessel classes can dock where those hosts have a compatible bay. Docking does not transfer ship ownership.
- Cruisers and carriers belong to NPC admirals and move autonomously. They are not player-owned. Corvette and frigate ownership is undecided; the rules below do not assign either class to players.
- An NPC deck fighter is supplied by its host’s finite hangar stock. The carrier does not borrow a parked player-owned ship to fill a wing. Launch reserves a carrier hull; destruction removes one hull. An incapacitated NPC pilot is unavailable for 24 hours, then returns with the same identity.
- Current scope: Pegasus and Bifrost support the shared roster. Resolute and both carriers use the class rule on their existing flight docking paths. New ship models, player-flyable vessels, persistent Resolute storage and new multicrew rosters are not unlocked by this classification.
